# Labwise — visual walkthrough

Every screen and state of the app, in the order a real person meets them. **All data is synthetic**: the reports, names and IDs come from `fixtures/golden/` and do not belong to anyone.

Screenshots are generated by `scripts/walkthrough.ts` against a production build in local mode, so they always match the code:

```bash
pnpm build && LABWISE_MODE=local LOCAL_DATA_DIR=.data-walkthrough pnpm start --port 3100
BASE_URL=http://localhost:3100 pnpm walkthrough   # → docs/screenshots/
```

Mobile shots are 390×844 (iPhone-sized); desktop shots are 1280×800.

## 12. Paying for more reports

The first report is free; samples are always free. After that the report waits, ready to explain, until a plan is chosen. Prices come from region config. Local mode uses a simulated checkout that goes through the same signed verification path as Razorpay.
